# OYU AI

OYU AI — 6-сынып оқушысының «Зерде» ғылыми жобасына арналған тегін статикалық сайт. Жоба төрт оюды таниды: Қошқармүйіз, Түйетабан, Құсқанат және Сыңарөкше.

## Сайт бөлімдері

1. Басты бет
2. Оюды тану
3. Оюлар әлемі
4. Менің зерттеуім

Тану Google Teachable Machine моделінің TensorFlow.js экспортымен тікелей пайдаланушы браузерінде орындалады. Суреттер серверге жіберілмейді, ақылы API, авторизация, Supabase және деректер базасы қолданылмайды.

## Жергілікті іске қосу

Node.js 20 немесе жаңарақ нұсқа қажет.

```bash
pnpm install
pnpm run dev
```

Жариялау алдындағы тексеру:

```bash
pnpm run typecheck
pnpm run build
```

Модель мен ою деректерін жаңарту жөніндегі қарапайым нұсқаулық: [КАК_ОБНОВИТЬ_МОДЕЛЬ_И_ОЮ.md](КАК_ОБНОВИТЬ_МОДЕЛЬ_И_ОЮ.md).

## GitHub Pages-ке тегін жариялау

1. Жобаны GitHub репозиторийіне жүктеңіз.
2. **Settings → Pages → Source** бөлімінде **GitHub Actions** таңдаңыз.
3. Өзгерістерді `main` немесе `master` тармағына жіберіңіз.
4. `.github/workflows/deploy.yml` сайтты автоматты түрде жинап, HTTPS арқылы жариялайды.

Hash-маршруттар және салыстырмалы файл жолдары GitHub Pages ішкі қалтасында да дұрыс жұмыс істейді. HTTPS камераны қолдануға мүмкіндік береді; пайдаланушы браузерде камераға рұқсат беруі керек.
