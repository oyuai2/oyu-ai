# OYU AI Teachable Machine model

The published browser model is stored here:

- `model.json` — TensorFlow.js model topology;
- `weights.bin` — trained weights;
- `metadata.json` — Teachable Machine metadata and labels;
- `model-info.json` — public model status used by the interface.

Current labels: `Қошқармүйіз`, `Түйетабан`, `Құсқанат`, `Сыңарөкше`.
